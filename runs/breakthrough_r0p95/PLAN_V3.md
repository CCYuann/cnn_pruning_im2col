# V3 硬體感知配額（凍結計畫）

凍結日期：2026-11-06，於任何本批模型訓練之前寫下。

## 來由
硬體改為 V3：cluster 週期 = 31 + tiles×max(q, 15)，q<15 不再省週期。以此公式重算 ResNet34 Dense 為 21,425,368 拍，與硬體文件完全相同。
既有模型重算（V3，3 seeds 平均）：fs 98% 20.74 ms、20.66 倍；q<15 的 cluster 占 50.3%，可免費補約 5821 個位置（+10.9%）。
fs 99% 12.53 ms，q<15 占 64.8%，約 8078 個位置（+30.3%）。硬體文件亦要求軟體端評估「q 補到 15」。

## 方法
fs = gradual + q 下限 1 + stem 全保留，為基準。
- fill15：每個 cluster 至少 15 個位置，**不扣預算**，權重數增加。--q-floor --q-floor-n 15 --free-fill --stem-keep
- budget15：每個 cluster 至少 15 個位置，**總權重不變**，由全網最弱的非保護位置扣回。--q-floor --q-floor-n 15 --stem-keep

## 判定
- fill15：validation 平均 >= +0.3pp 且 2/2 為正，且 V3 週期增加 <= 0.5%，才算有增益。另報權重與 index 儲存增加量。
- budget15：V3 週期至少少 5%，且 validation 平均 >= -0.1pp，才算硬體增益。
- 須報 kept、sparsity、q=0、RGB、最大 q。
通過者才以 seeds 6/7/8 確認；seeds 6/7/8 的 test 已讀過一次，若再用須揭露，或改用新 seeds 9/10/11。
