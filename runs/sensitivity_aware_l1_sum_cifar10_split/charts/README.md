# 圖表說明

這裡放 `l1_sum sensitivity-aware` 和新方法最佳 sensitivity-aware 版本的比較圖。

- `l1_sum_accuracy_speedup_r0p6.png`：ratio 0.6 下，l1_sum 的 accuracy bar 與 speedup line。
- `l1_sum_accuracy_speedup_r0p7.png`：ratio 0.7 下，l1_sum 的 accuracy bar 與 speedup line。
- `acc_l1_vs_newbest_r0p6.png`：ratio 0.6 下，l1_sum 和新方法最佳版 accuracy 對照。
- `acc_l1_vs_newbest_r0p7.png`：ratio 0.7 下，l1_sum 和新方法最佳版 accuracy 對照。
- `acc_gap_l1_minus_newbest_r0p6.png`：ratio 0.6 下，`l1_sum - 新方法最佳` 的 accuracy 差距。
- `acc_gap_l1_minus_newbest_r0p7.png`：ratio 0.7 下，`l1_sum - 新方法最佳` 的 accuracy 差距。

gap 圖大於 0 代表 l1_sum 比新方法最佳高；小於 0 代表新方法最佳比較高。
