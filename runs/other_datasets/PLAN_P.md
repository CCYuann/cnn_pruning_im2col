# 計畫 P：中段剪枝率 92%、95%（2026-11-09 凍結，下列新組別皆尚未產生）

背景：使用者要求先看 92–95%，不只看 98–99% 的極端點。已有資料：5 個模型的 90%（rewind、gradual+floor），ResNet34 的 95%（rewind、gradual+floor、unstructured、ft_const）。
目的：補齊 90–99% 之間的曲線，看方法優勢從哪個比例開始出現，並畫出精度對 V3 週期的曲線。

組別：CIFAR-100，ResNet34、ResNet-56、VGG16-BN、GoogLeNet、DenseNet121，92% 與 95%，seeds 0/1/2：
- rewind（原論文 mask 規則 + LR rewinding）
- gradual+floor
- fill15（gradual + 每個 cluster 至少 15 個位置，不扣預算）
- gradual_unstructured（存下 8 個 filter 的位置聯集，用於 V3 週期）
已存在的組別（ResNet34 95% 的 rewind、gradual+floor）不重跑。先跑 95%，再跑 92%。

判定（test 直接判定，門檻同計畫 N/O）：
- P1：gradual+floor 對 rewind，配對平均 >= +0.3pp 且 3/3 為正，逐模型、逐比例。
- P2：fill15 對 gradual+floor，配對平均 >= +0.3pp 且 3/3 為正，且 V3 週期不超過 1.005 倍；另報權重增加量。
- P3：gradual_unstructured 只描述，報同稀疏度的結構化代價與等週期比較。
週期為 V3 公式預測，新模型只報 FP32。

## 結果（2026-11-09 20:30 完成，114 條，0 失敗；CIFAR-100 FP32 test，seeds 0/1/2）
V3 週期為公式預測；gradual_unstructured 用存下的 8 個 filter 位置聯集計算。

### P1：gradual+floor 對 rewind
| 模型 | 92% | 95% |
|---|---|---|
| ResNet34 | 76.02 → 75.57，-0.46/-0.50/-0.41，**未過（3/3 為負）**；49.85 → 39.42 ms | 74.59 → 74.54，+0.08/-0.52/+0.29，未過；34.57 → 25.71 ms |
| ResNet-56 | 63.80 → 66.44，+2.62/+2.35/+2.93，成立；4.02 → 3.87 ms | 59.13 → 63.29，+6.00/+3.76/+2.73，成立；3.22 → 3.16 ms |
| VGG16-BN | 71.16 → 71.56，-0.01/+0.54/+0.65，未過（差一個 seed）；29.23 → 26.11 ms | 68.88 → 71.02，+2.83/+1.81/+1.78，成立；20.85 → 18.15 ms |
| GoogLeNet | 73.06 → 74.23，+1.37/+0.49/+1.65，成立；18.51 → 18.83 ms | 70.70 → 73.37，+3.61/+1.84/+2.55，成立；12.55 → 12.98 ms |
| DenseNet121 | 71.29 → 76.69，+4.30/+6.13/+5.78，成立；27.17 → 32.29 ms | 68.51 → 75.43，+6.07/+7.10/+7.57，成立；20.06 → 23.33 ms |

- ResNet34 在 92% 輸 rewind 0.46pp（3/3 為負），95% 打平，98% 起才贏；週期在每個比例都少 20–30%。
- GoogLeNet、DenseNet121 的 gradual+floor 週期比 rewind 多 2–16%，增益不是在同週期下取得。
