# 計畫 W：給原論文流程公平的微調 LR（2026-11-10 凍結，下列新組別皆尚未產生）

背景：計畫 S（90%）的主判定是 gradual+floor 對原論文流程（ft_const：原論文 mask 規則，一次剪完，固定 LR 微調 60 epochs）。原論文沒有給 LR，我們假設 0.001。計畫 U 顯示 95% 時 ResNet18/34/50 對原論文流程的增益幾乎都來自 LR，所以 0.001 可能讓原論文流程吃虧，審稿人會質疑。本計畫用 validation 為每個模型選一個最好的固定 LR，再用 test 比一次。

## 組別（CIFAR-100，90%，seeds 0/1/2，8 個模型）
ResNet18、ResNet34、ResNet50、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet、DenseNet121。
- LR 候選：0.001（已存在，計畫 S）、0.003、0.01、0.03（新增，worker 參數 `--ft-lr`）。
- 新增 8 模型 × 3 LR × 3 seeds = 72 條，前綴 `w_`，結果目錄後綴 `ft_const_r90_lr<值>`。
- gradual+floor 與 rewind 的 90% 結果已存在，不重跑。

## 選 LR（只看 validation）
每個模型取 seeds 0/1/2 的 `final_validation` 平均最高的 LR（validation 是從 50k 訓練集切出的 5,000 張，不是 test）。平手取較小的 LR。選定後不得更改。

## 判定（test，每模型讀一次）
- **W1（主判定）**：gradual+floor 對「選定 LR 的 ft_const」，配對平均 >= +0.3pp 且 3/3 為正，逐模型。這取代計畫 S 的 S1 成為論文中「對原論文流程」的主數字；S1 保留為「LR 0.001」的結果。
- **W2（描述）**：rewind 對選定 LR 的 ft_const 的差，看高 LR 重訓的效果還剩多少。
- 其他 LR 的 test 精度只列在附表供透明，不能用來重選 LR。
- 若 0.03 被選中（候選上界），要在報告中註明「上界未封閉，可能有更高的最佳 LR」，不追加 LR。

## 結果（2026-11-10 23:57，新增72/72成功，0失敗）

90% 的公平固定 LR 對照（W1）為 8/8 通過；通過：ResNet18、ResNet34、ResNet50、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet、DenseNet121。每模型 seeds 0/1/2、n=3。W1 取代 S1 成為論文中「對原論文流程」的主數字；LR0.001 的 S1 8/8 僅保留為歷史對照。

結果來源：七個模型選回 LR 0.001，W1 引用計畫 S 已讀過的 test；只有 ResNet-56 選 LR 0.003 的 ft_const 是新增主對照。所有 floor／rewind 均沿用 S；W 並非新 seeds 的獨立重現。ResNet-56 的 validation 以 61.01% 對 60.83% 選定 0.003，即使其 test 61.42% 低於 0.001 的 61.71%，仍維持 validation 的選擇，未依 test 重選。

### 保留與證據

- 本研究只有浮點精度，worker 在 CUDA 以 AMP float16 評估，新模型沒有 Q15 流程。
- 週期為 V3 公式預測：每 cluster 31 + Hout × ceil(Wout/8) × max(q,15) 拍，50 MHz、僅卷積層；不是 V3 RTL 實測。
- 每組 n=3；門檻不是統計顯著性檢定。負面結果照報，未依 test 調參或重跑 test 推論。
- W1 門檻維持配對平均至少 +0.3pp 且 3/3 為正，未修改門檻或因 test 重選。
- LR 只用 seeds 0/1/2 的 final_validation 平均選，平手取較小；PLAN_W_LR_SELECTION.json 在執行 test 判定腳本前已獨立寫入。未因 test 重選。
- LR 僅限 0.001、0.003、0.01、0.03；原論文未給 LR，選出的設定不代表作者實際配方。
- 選到候選上界 0.03 的模型：無。此候選集合內沒有模型選到上界；仍不能視為全域 LR 最佳化。

**下界未封閉（2026-11-11 補充，事後檢查）。** 8 個模型中有 7 個選中的是候選中最小的 LR 0.001，validation 隨 LR 增大而單調下降；只有 ResNet-56 的最佳值在 0.003。所以「上界未選中」不代表網格已封閉：更小的固定 LR（如 0.0003）是否更好尚未測試，W1 的「公平 LR」只在 0.001–0.03 範圍內成立。另一方面，這也表示 rewind 對 ft_const 的優勢（W2）不是因為 0.001 太小；把固定 LR 調大只會更差，優勢來自 rewind 的「先高後以 cosine 降低」的重訓排程。計畫 U 摘要中「LR 效果」應讀作「重訓排程效果」。
- 附表其他 LR 的 test 只供透明，不用來選 LR；W2 只描述，不設門檻。
- LR 不改一次剪枝的 mask 規則，預測週期沿用 S。GoogLeNet 的 floor 比 ft/rewind 多約1.1%，DenseNet121 多約17.5%，精度增益不能稱為同週期改善。
