# 計畫 S：以 90% 為基準的跨模型驗證（2026-11-09 22:55 凍結，下列新組別皆尚未產生）

背景：使用者指示不要只看 98–99% 的極端比例，改以 90% 為基準，檢查做法能否推廣到其他模型。
90% 也是原論文（Pham et al., 2025）報告精度的最高比例，在這個比例和原論文流程比最公平。

## 比較的三種流程（同一個剪枝率 90%）
- ft_const：原論文流程。原論文 mask 規則（global unstructured 稀疏度 → 每個 cluster 照抄，cluster 內 L1 選位置），一次剪完，固定 LR 0.001 微調 60 epochs（原文未給 LR，此為假設）。
- rewind：同一個 mask，改用 LR rewinding 重訓 60 epochs。
- gradual+floor（我們）：逐步剪枝 + 每個 cluster 至少 1 個位置，60 epochs。

## 模型（CIFAR-100，seeds 0/1/2）
ResNet18、ResNet34、ResNet50、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet、DenseNet121，共 8 個。
ResNet18、ResNet-110 為新加入（Dense 100 epochs）；兩者全部為 3×3/1×1、groups=1，符合 V3。
已存在的組別不重跑（ResNet34 三種皆有；其餘模型已有 rewind 與 gradual+floor）。
另在 VGG16-BN、ResNet-56 的新 seeds 3/4/5（計畫 R 的 Dense）上跑三種流程，作為 90% 結論的重現。

## 判定（test 直接判定，每條讀一次）
- S1（主判定）：gradual+floor 對 ft_const，配對平均 >= +0.3pp 且 3/3 為正，逐模型。
- S2：gradual+floor 對 rewind，同門檻。
- 每組另報 V3 預測週期與對 Dense 的掉點；同剪枝率不保證同週期，週期較多的模型須註明。
新模型沒有 Q15 流程，只報 FP32。

## 結果（2026-11-10 01:37 完成，Asia/Taipei）

計畫 S 的 57 條新工作全部完成，57/57 個回傳碼為 0、失敗 0 條；沿用既有 Dense、rewind 與 gradual+floor 組別，沒有重跑既有訓練。使用 scripts/decide_plan_s.py 統一判定，數據保存於 PLAN_S_RESULTS.json，執行輸出保存於 PLAN_S_DECISION.txt。

90% 剪枝率下，gradual+floor 對固定 LR 微調（S1）在八個模型中 8/8 通過；對 LR rewinding（S2）為 4/8 通過。每模型 seeds 0/1/2、n=3；通過僅表示達到事前門檻，不等同統計顯著。

### 解讀與保留

- ft_const 採原論文的 mask 規則與一次剪完後微調的流程，但固定 LR 0.001 是本研究的假設，原文未提供 LR；不能視為完整重現原論文配方。
- 同剪枝率不代表同週期。GoogLeNet 22.41 → 22.65 ms（+1.1%）；DenseNet121 32.19 → 37.81 ms（+17.5%）；兩者的精度增益不是在同週期下取得。ft_const 與 rewind 共用相同 mask，因此採用相同預測週期。
- 所有週期皆為 V3 公式預測：每個 cluster 為 31 + Hout × ceil(Wout/8) × max(q, 15) 拍，50 MHz，只計卷積層；不是 V3 RTL 實測或端到端推論時間。
- 本計畫沿用「FP32」標記指未做 Q15 的浮點模型；dataset_pruning_worker.py 實際在 CUDA 以 AMP float16 評估，並非全 FP32 算術。此處只補充精度設定，未重跑 test。新模型尚無 Q15 整數流程，不得外推整數模型精度。
- 門檻維持配對平均至少 +0.3pp 且三個 seeds 全為正；負面結果照報，不依 test 調參或改門檻。判定使用一次產生的 PLAN_S_RESULTS.json 與腳本輸出，未重跑 test 推論。
