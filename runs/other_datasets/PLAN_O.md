# 計畫 O：V3 免費容量（fill15）與 VGG 崩潰對照（2026-11-09 凍結，下列組別皆尚未產生）

背景（計畫 N 的結果）：
- CIFAR-100 上 gradual+floor 對 rewind 在 5 個模型 98/99% 全部成立，但結構化代價（對 gradual_unstructured）為 -2.2 至 -11.5pp，ResNet-56 最大。
- ResNet-56 的 V3 週期在 98% 與 99% 幾乎相同（2.74 / 2.72 ms），代表多數 cluster 已低於 q=15，週期由 max(q,15) 的下限決定。
- 依 V3 的週期模型，q<15 的 cluster 補到 15 個位置不增加週期。CIFAR-10 ResNet34 上 fill15 未通過（-0.09pp），但那裡結構化代價本來就小。
- VGG16-BN 的 rewind 在 98/99% 全部崩到 1%（一次剪造成整層失效），+67pp 的差距主要是基準崩潰，不能當成方法增益。

## O1：fill15（不訓練以外的條件全部沿用 gradual+floor）
--arm gradual --q-floor --q-floor-n 15 --free-fill，CIFAR-100，ResNet34、GoogLeNet、DenseNet121、VGG16-BN、ResNet-56，98/99%，seeds 0/1/2，共 30 條。
判定（逐模型、逐比例）：對 gradual+floor 配對 test 平均 >= +0.3pp 且 3/3 為正，且 V3 預測週期不超過 gradual+floor 的 1.005 倍。
另報權重數增加量。fill15 的權重數多於名目比例，故結論寫成「同 V3 週期」而不是「同稀疏度」。

## O2：VGG16-BN 一次剪加下限
--arm rewind --q-floor，98/99%，seeds 0/1/2，共 6 條。不設門檻，只描述：拆開「每個 cluster 至少 1 個位置」與「逐步剪枝」對 VGG 崩潰的貢獻。

## O3：unstructured 在 V3 上的週期（不訓練）
用 Dense checkpoint（seeds 0/1/2）的全域 magnitude unstructured mask，98/99%，每個 cluster 的 q 取 8 個 filter 的位置聯集，用 V3 公式算週期。
這是一次剪的近似（gradual_unstructured 的 mask 沒有存下），只描述：結構化的精度代價換到多少週期。

test 於每條結束時讀一次。V3 週期為公式預測。

## O3 補充（凍結於 13:25，O3 的一次剪近似結果算出之後）
一次剪近似算出後，追加 gradual_unstructured 98/99% seed 0 的重跑（--tag _union，5 個模型共 10 條），存下 8 個 filter 的位置聯集，用實際逐步 mask 算 V3 週期，檢查近似是否偏差。
重跑的 test 只用來看 seed 0 的重現性，不取代計畫 N 的數字。

## 結果（CIFAR-100 FP32 test，seeds 0/1/2）

- 10 組通過 8 組；週期條件全部滿足，fill15 的週期反而少 1–18%（保護從逐步剪枝的起點就生效，名額不再集中到大 cluster）。
- 權重增加隨模型變窄、比例變高而變大。ResNet-56 的 98% 與 99% 補完後 mask 相同（266 個 cluster 皆 q=15，實際稀疏度 96.25%），兩者只差排程；結論須寫成「同 V3 週期」，不是「同稀疏度」。
- 與計畫 P 合看：92–95% 時 fill15 幾乎不改 mask，只有 ResNet-56 95% 通過；fill15 是極端比例下的修正。

### O2：VGG16-BN 一次剪加下限（rewind + q-floor）
98% 52.71/1.00/58.69%（平均 37.47%，一個 seed 崩潰；10.92 ms），99% 三個 seeds 全為 1.00%。每個 cluster 至少 1 個位置不足以避免崩潰，VGG 的恢復主要來自逐步剪枝。
