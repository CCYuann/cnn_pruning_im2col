# 90–95% 跨模型驗證與高剪枝率實驗統整（截至 2026-11-11）

本文件以 Cross-Filter Structured Pruning 在 90% 剪枝率的跨模型驗證為基準，延伸至 95%；另整理 98–99% 延伸實驗，以及在 mask-aware 加速器 V3 上的週期分析。
細節與逐條判定見文末的檔案索引；本文件只列結論與主要數字。

所有週期皆為 V3 公式預測（50 MHz，僅卷積層），尚未在 V3 RTL 上量測；RTL 逐位元驗證是在 V2.3 RTL 上做的。

## 1. 結論摘要

1. **90% 主線：以五個 LR 的 validation 選擇後之 X1 為準。** X1 為 8/8 模型通過；通過：ResNet18、ResNet34、ResNet50、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet、DenseNet121；未過：無。X1 取代 W1 成為論文中「對原論文流程」的主數字；W1／S1 保留為歷史對照。 沿用 W1：ResNet18、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet（5/8）；新增主對照：ResNet34、ResNet50、DenseNet121（3/8）。改選模型的主對照使用新增的 LR 0.0003；其餘模型直接引用已讀過的 W1。 選到 0.0003：ResNet34、ResNet50、DenseNet121；下界仍未封閉，可能有更小的最佳 LR，依凍結計畫不再追加。 每模型 seeds 0/1/2、n=3；0.0003 是看過 W validation 後才事後補測，門檻非顯著性檢定（見5.9、5.10）。

**W 的下界疑慮與 X 補測（事後延伸）。** W 時七模型選到原候選最小 LR 0.001，因此看過 W validation 後補測 0.0003；X 的結論：X1 為 8/8 模型通過；通過：ResNet18、ResNet34、ResNet50、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet、DenseNet121；未過：無。X1 取代 W1 成為論文中「對原論文流程」的主數字；W1／S1 保留為歷史對照。 沿用 W1：ResNet18、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet（5/8）；新增主對照：ResNet34、ResNet50、DenseNet121（3/8）。改選模型的主對照使用新增的 LR 0.0003；其餘模型直接引用已讀過的 W1。 選到 0.0003：ResNet34、ResNet50、DenseNet121；下界仍未封閉，可能有更小的最佳 LR，依凍結計畫不再追加。 計畫 U 摘要的「LR 效果」應讀作「重訓排程效果」；固定 LR 網格不單獨隔離先高後降等排程環節的作用（見5.9、5.10）。
2. **95% 延伸（計畫 T）。** 95% 下 T1 共 7/8 模型達門檻，其中 ResNet34 是已讀舊結果，其餘 7 個模型新增 ft_const 對照；T2 共 4/8 達門檻，但只有 ResNet18、ResNet-110 是新結果（0/2 達門檻），其餘 6 模型為引用舊結果。每模型 seeds 0/1/2、n=3；通過不等同統計顯著。 新增的 7 個 T1 對照為 6/7 通過；唯一未過的 ResNet-110 雖平均 +3.03pp，但配對差 +3.14/-0.86/+6.82pp，只有 2/3 為正。ResNet18 的 T2 平均 +0.28pp 未達 +0.3pp，且有 -0.01pp 的 seed 反例；ResNet-110 的 T2 平均 -1.10pp，兩者均未過。 新 T2：ResNet18 +0.28pp（未過）（90% +0.14pp）；ResNet-110 -1.10pp（未過）（90% +0.60pp）。T4 只作描述：95% 的 T1 差值不小於 90% 的模型為 7/8；差值縮小者：ResNet-110 +3.34 → +3.03pp。未對 T4 設門檻或作統計判定。（見 5.6）。
3. **原因拆解（計畫 U／V）。** U 的 seeds 0/1/2（每組 n=3）中，過程 7/7 正、位置 6/7 正、單獨借配額 6/7 負。V 在兩模型95%、seeds 3/4/5（每模型 n=3）的結果：V1 逐步過程為正（兩模型）：未重現；V2 位置選擇為正（兩模型）：重現；V3 單獨借配額為負（僅 ResNet-56）：重現。V1 逐步過程為正（兩模型）未重現，該結論降級為「只在 seeds 0/1/2 觀察到」；拆解順序固定，過程包含起點差異（見5.7、5.8）。
4. **98–99% 有延伸證據，不能概括為剪得越多優勢越大。** ResNet34 在 90–95% 與 rewind 差距在雜訊內（92% 甚至 -0.46pp），98–99% 才拉開；GoogLeNet、DenseNet121、ResNet-56 在 90% 就已領先。90% → 95% 時，VGG16-BN 對 rewind 轉為通過，但 ResNet34、ResNet50 仍未過；這些是事後觀察，不能推論普遍單調趨勢（見 5.4、5.6）。
5. **CIFAR-10 的主方法是 fs**（逐步剪枝 + q 下限 + conv1 全保留）。99% 對 rewind +1.06pp（6 seeds，6/6 為正），週期少約 27%。
6. **CIFAR-10 會掩蓋精度損失，方法證據要看 CIFAR-100。** CIFAR-100 上隨機 mask 輸 2–3pp，能分辨方法；99% 對 Dense 掉約 7pp，CIFAR-10 只掉約 2pp。
7. **KD 在 CIFAR-100 的 90–98% 有效**，98% 約 +1pp，兩批 seeds 皆重現；在 CIFAR-10 有害，在 99% 無效。
8. **主線應是 ResNet34。** V3 每 tile 至少 15 拍，ResNet50 最快 18.95 ms，ResNet34 最快 5.73 ms，且 ResNet50 在 CIFAR-100 全面較差。
9. **軟硬體一致。** Q15 整數流程只掉 0.0–0.4pp；兩個定案模型在 RTL 36/36 層逐位元一致，週期估算與 RTL 量測差 0.15–0.35%。
10. **5 個模型都成立（CIFAR-100）。** ResNet34、ResNet-56、VGG16-BN、GoogLeNet、DenseNet121 在 98/99% 對 rewind 全部 3/3（VGG16-BN 為對手崩潰，不算方法增益）；照原論文微調（固定 LR，ResNet34）在 99% 落後 10.32pp。
11. **在 V3 上，結構化比 unstructured 划算。** 同稀疏度下 unstructured 高 0.6–11pp，但 V3 要跑 8 個 filter 的位置聯集，週期是 1.5–7 倍（92–95% 為 3.4–6.4 倍）；在不多於 unstructured 98% 的週期下，我們的 90% 在 5 個模型都更準。
12. **fill15 是極端比例的修正。** q 低於 15 不省週期，補到 15 不花週期：98–99% 的 10 組中 8 組通過（ResNet-56 99% +15pp），週期反而少 1–18%；92–95% 幾乎無作用。權重數會增加，要寫成「同 V3 週期」。
13. **KD 不是通用增益。** 只在 ResNet34、VGG16-BN 的 98% 有效（可疊在 fill15 上），GoogLeNet、DenseNet121 無效，ResNet-56 有害。

## 2. 名詞

| 名稱 | 意義 |
|---|---|
| cluster | 8 個 filter 一組（Tm=8），共用同一個 K-position mask |
| q | 每個 cluster 保留的 K 位置數；K = Cin × Kh × Kw |
| rewind | 由 Dense 一次產生 mask，配額與原論文相同（先做 global unstructured 剪枝，每個 cluster 照抄其稀疏度，cluster 內以 L1 加總選位置），再以 LR rewinding 重訓 60 epochs |
| gradual | 前 2/3 epochs 以三次曲線逐步提高剪枝率，每 2 epochs 更新 mask |
| floor（q 下限） | 每個 cluster 至少保留 1 個位置，總權重數不變 |
| fs | gradual + floor + conv1 全保留 |
| fill15 / budget15 | 每個 cluster 至少 15 個位置；fill15 額外加權重，budget15 總權重不變 |
| KD | Dense 模型當 teacher，T=4；alpha 為 soft target 權重，預設 0.9 |
| Q15 | 加速器的整數流程：per-tensor MSE scale、分支內 CLE（k≤8）、逐層 bias correction（256 張），right_shift 夾到 48 |

## 3. 方法紀律

- 每個計畫在跑之前寫下組別與門檻；早期以 validation 判定後才讀 test，計畫 R、S、T 依預先凍結規則直接以 test 判定，每個模型的 test 只讀一次，不依 test 調參。
- 開發 seeds 上通過的方法，必須在沒看過的新 seeds 上再通過一次，才算成立。
- 門檻：CIFAR-10 為配對平均 ≥ +0.3pp 且所有 seed 為正；CIFAR-100 validation 雜訊較大（單模型標準誤約 0.65pp），自計畫 I 起改為 ≥ +0.7pp。計畫 R、S、T 的 test 判定依各自凍結規則，為配對平均 ≥ +0.3pp 且 3/3 為正。
- 事後才提出的想法、讀錯的資料、判定與 test 不一致的情形都照實揭露，負面結果照報。

- U／V 依凍結拆解規則直接用 test：配對平均 ≥ +0.3pp 且 3/3 正為正效果，≤ −0.3pp 且 3/3 負為負效果，其餘不確定。W 先只用 validation 選 LR，再以 test 判 W1（平均 ≥ +0.3pp 且 3/3 正）；W2 僅描述，其他 LR test 不參與選擇。

### 4.3 conv1 色盲

逐步剪枝的全域 L1 排序會把 conv1（K=27）剪到 3–5 個位置，有時整個顏色通道消失（例如 G2 seed4 只剩 G 通道）。
fs 保留 conv1 全部位置後修好這個問題。G3 中增益集中在缺色的配對：缺色 3 對平均 +0.99pp，顏色齊全 6 對平均 +0.10pp。
CIFAR-100 的 conv1 都保有 RGB，fs 在那裡沒有增益（計畫 H1）。

- 沿用 W1：ResNet18、ResNet-56、ResNet-110、VGG16-BN、GoogLeNet（5/8）；新增主對照：ResNet34、ResNet50、DenseNet121（3/8）。改選模型的主對照使用新增的 LR 0.0003；其餘模型直接引用已讀過的 W1。 floor／rewind 均引用 S；沿用 W1 的 test 先前已讀過，不把它們算成新結果。X 使用相同 seeds，並非新 seeds 的獨立重現。
- X1 門檻維持配對平均 ≥ +0.3pp 且 3/3 為正；每模型 n=3，門檻不是統計顯著性檢定。X2 只描述；附表各 LR test 不參與選擇，未選 0.0003 者的該 test 僅供附表。
- 僅浮點結果，worker 在 CUDA 以 AMP float16 評估；新模型沒有 Q15 流程。
- V3 週期沿用 S 的公式預測：每 cluster 31 + Hout × ceil(Wout/8) × max(q,15) 拍，50 MHz、僅卷積層，非 RTL 實測。GoogLeNet／DenseNet121 的 floor 比 ft/rewind 多約 1.1%／17.5% 週期，不能稱為同週期增益。

**事後分析（2026-11-11，看過 test 後才做，不屬於凍結判定）：**
- 改選 0.0003 的三個模型（ResNet34、ResNet50、DenseNet121），0.0003 和 0.001 的 validation 只差 0.10–0.14pp，test 則相反，是 0.001 較高（差 0.11–0.31pp）。所以這三個模型的 X1 比 W1 大（ResNet34 +1.45→+1.76、ResNet50 +1.33→+1.45、DenseNet121 +3.05→+3.17），是選 LR 時的雜訊，不代表我們的方法變好。
- 保守下限：每個 seed 各自取五個 LR 中 test 最高的 ft_const 當對手（等於用 test 挑 LR，是對手最有利的情況），gradual+floor 仍然 8/8 模型 3/3 為正。平均差：ResNet18 +1.81、ResNet34 +1.45、ResNet50 +1.33、ResNet-56 +5.69、ResNet-110 +3.34、VGG16-BN +1.66、GoogLeNet +4.22、DenseNet121 +3.04（seeds 0/1/2，n=3）。
- 0.0003–0.001 之間的 validation 曲線幾乎是平的。下界在形式上仍未封閉，但目前看不出再降 LR 能讓對手多拿 1pp 以上。這是推測，沒有實測。
- 建議論文正文報 X1，並附上這個保守下限，回應「對手 LR 沒調好」的質疑。

## 7. 硬體相關

- **V3 週期模型：** 每個 cluster 31 + Hout × ceil(Wout/8) × max(q, 15) 拍。q 低於 15 不省週期，只多佔權重與載入頻寬。
- **V3 下限（32×32）：** ResNet34 5.73 ms（最多 74.8×），ResNet50 18.95 ms（最多 25.3×）。
- **mask 落點影響很大：** 同樣約 53,200 個位置，放在 layer4 便宜、放在 layer1/2 貴，週期可差 25%。開發 seeds 1/2 的 ms 因此不能和 seeds 3–11 比。
- **Q15：** right_shift 可能出現 49–55（近乎死掉的 channel），夾到 48 後 5000 張 logits 完全相同。peak_acc 約 2^29 來自這些 channel 的 bias，真實卷積和峰值約 1.5–1.8e5。
- **RTL 逐位元驗證（V2.3）：**
  - CIFAR-10 fs 98% seed6，兩張影像皆 36/36，量測 1,160,791 拍，估算差 0.35%。
  - CIFAR-100 KD 98% seed3，一張影像 36/36，量測 686,221 拍，估算差 0.15%。
  - 涵蓋 q=27 的 conv1、q 最大 250 以上的 cluster、stride 2、1×1 downsample、2^29 bias 與 right_shift 48。

## 10. 與原論文的差異與限制

原論文（Pham et al., IEEE Access 2025）只測 50–90% 的精度，加速比較用約 60%，資料集為 CIFAR-10、Animals-10、ImageNette，流程是一次剪完再 fine-tune。
本研究延伸到 98–99%，找出原流程在極端剪枝率下的失效點（cluster q=0、conv1 色盲、一次剪枝崩潰）並修正，再用自己的加速器量化週期。

限制：
- rewind 基準的 mask 與原論文相同，差別只在重訓：rewind 用 LR rewinding，原論文只寫「fine-tune」、未給 LR。照原文微調的對照（固定 LR 0.001）見計畫 M（runs/other_datasets/PLAN_M.md）。
- CIFAR-100 ResNet34 Dense seeds 3/4/5 誤用了拉長的 LR 曲線（起始 0.0655，非 0.1），計畫 J、L 的配對比較仍有效，但不是「相同配方」的重現；計畫 M 以正確配方的 seeds 6/7/8 重做（揭露於 PLAN_H.md）。
- V3 週期為公式預測；RTL 驗證在 V2.3 上做，tb 副本放大了陣列與 MEMORY_DEPTH，未跑 backpressure 與 Reload。
- residual add、pooling、FC 仍在軟體；不是端到端硬體推論。
- 計畫 H 彙整時曾意外印出 fs 組 seeds 0/1/2 的 test，判定已先寫下，未受影響（揭露於 PLAN_H.md）。
